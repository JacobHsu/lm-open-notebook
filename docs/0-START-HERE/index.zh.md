## 你能做什麼?

- 📄 **上傳內容**:PDF、網頁連結、音訊、影片、純文字
- 🤖 **與 AI 對話**:針對你的文件提問,並附上引用來源
- 📝 **產生筆記**:AI 自動整理摘要與洞見
- 🎙️ **製作 Podcast**:把研究內容變成專業的音訊內容
- 🔍 **搜尋**:對所有內容進行全文與語意搜尋
- ⚙️ **轉換**:萃取洞見、分析主題、產生摘要

## 為什麼選 Open Notebook?

| 功能 | Open Notebook | Notebook LM |
|---------|---|---|
| **隱私** | 自架伺服器,自己掌控 | 雲端,Google 的伺服器 |
| **AI 選擇** | 17+ 種供應商 | 只能用 Google 的模型 |
| **Podcast 主持人** | 1-4 位可自訂 | 只有 2 位 |
| **費用** | 完全免費 | 免費(但用你的資料換) |
| **離線使用** | 可以 | 不行 |

## 前置需求

- **Docker**:所有路線都會用到 Docker(免費)
- **AI 供應商**:雲端 API 金鑰,或是使用免費的本機模型(Ollama)
